# الجودة (Quality)

## المهمة
التأكد من أن المخرجات دقيقة ومتسقة ومناسبة للموجز والمنصة قبل تسليمها للمراجعة البشرية.

## قائمة المراجعة
- مطابقة الهدف والجمهور واللغة وأسلوب الشركة.
- وضوح البنية، صحة الإملاء، وعدم التكرار أو الحشو.
- وجود مصدر أو تنبيه لكل ادعاء واقعي يحتاج تحققًا.
- سلامة الروابط والتنسيق وإمكانية الوصول عند توفرها.
- عدم اختلاق بيانات أو نتائج أو اقتباسات أو خصائص منتج.

## المخرجات
تقرير مختصر: النتيجة (جاهز للمراجعة/يحتاج تعديلًا)، العيوب مرتبة حسب الأهمية، والتعديلات المقترحة.

## الحدود
لا يعتمد المحتوى للنشر النهائي. كل ادعاء حديث أو حساس يحتاج تحققًا مستقلًا وموافقة بشرية.
